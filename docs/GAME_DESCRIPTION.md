# 遊戲介紹

三百年前的臺灣，你與姊姊意外回到了過去。要回到現代，得先在這片土地上重新扎根——蒐集木頭、竹子、茅草與石頭，透過工藝與文化卡累積能力，一磚一瓦蓋起屬於自己族群的家屋。

你將扮演邵族、噶瑪蘭族、拉阿魯哇族或賽德克族的一員，與 1 到 3 位其他玩家（真人或電腦）同桌競逐。每輪擲骰決定行動點數，你可以拿素材、抽卡、交易、偷襲，也可以選擇分享素材或與人共學——競爭與合作都能推進你的進度。牌桌上還會不時翻出公共事件，讓每一輪的策略節奏都不太一樣。

先完成 4 間本族家屋，就掌握了勝局的關鍵。

# 基本資訊

🎮 類型：策略卡牌桌遊（回合制、資源管理）

🖥 平台：網頁瀏覽器（桌機與手機皆可遊玩）

👥 適合人數：2–4 人（可搭配電腦玩家，或透過連線與朋友對戰）

⏱ 遊戲時間：約 15–20 分鐘

🎯 建議年齡：內建 STEAM 教學任務台涵蓋國小 1–2 年級以上程度，一般建議 8 歲以上；正式分級尚待確認

🌏 支援語言：繁體中文

# 玩家將體驗

玩家會擲骰，看著點數決定這一輪能做幾件事，然後在拿素材、抽卡、蓋家屋之間快速盤算。

蒐集木頭、竹子、茅草與石頭，湊不齊的時候，找其他玩家交易，或是賭一把偷襲對手的素材庫。

在文化卡與工藝卡之間做選擇，看著手上的卡一張張變成家屋的一部分。

遇到「交流市集」「互助工班」這類事件時，玩家會發現分享素材、陪對手共學也能為自己加分——牌桌上不是只有搶奪，也有值得合作的時刻。

看著自己的家屋一間一間立起來，直到第四間完成，回到現代的路，也就近了一步。

# 操作方式

滑鼠：點擊中央牌桌的牌庫直接抽卡，點擊手牌與行動按鈕即可執行動作。

鍵盤：手牌與主要互動元件皆可用 Tab 聚焦、Enter／Space 觸發；開啟的視窗可用 Escape 關閉、Tab 循環焦點。

手機：畫面會依螢幕寬度自動改為直向堆疊排版，觸控尺寸已針對手機操作調整。

控制器：目前不支援。

# 教育價值（如果適用）

遊戲以臺灣原住民族的家屋、工藝與傳說故事為題材設計卡牌，讓玩家在策略選擇之間，自然接觸到不同族群的文化脈絡。

除了遊戲本身，專案也內建一個 STEAM 教學任務台：老師可以依國小低、中、高年級、國中或高中五個階段，把遊戲中的建築卡與素材卡轉成雨水、風力、遮陽、材料特性、聚落配置等探究任務，產生附帶教學流程、評量與延伸活動的教案。

需要特別說明的是：目前版本是教學原型，卡牌只作為「遊戲觀察物」，教案中的模型測試結果不代表任何真實族群的文化事實；具體族群內容仍標示為待審校，正式使用前需要文化顧問確認來源與授權。
