# 02 風格指南

## 設計北極星

名稱：活的文化策略檔案。

感受：深林中的火光、被保存與重新打開的文化記憶、玩家親手完成聚落。畫面要有主機遊戲的敘事張力，但資訊必須像成熟策略遊戲一樣可讀。

避免：

- 泛用 PS5 側欄模板。
- 全站金框、全站玻璃、全站發光。
- 一套混合紋樣代表所有原住民族。
- 只有山林與火光、卻看不見卡牌、建屋與玩家選擇。
- 把文化內容做成裝飾性標籤。

## 設計參數

### Variance 8

- 首頁採非對稱構圖，重要場景可跨欄、疊圖與突破容器。
- 不同畫面有獨立節奏，但共享色彩、字體、間距與互動語彙。
- 遊戲元件可有世界觀質感，不做通用 SaaS 卡片牆。
- 變化必須服務資訊層級；不能每個區塊都用不同特效。

### Motion 7

- 使用場景進場、卡牌揭示、素材移動、家屋完成與狀態轉換。
- 動態主要回答：發生了什麼、東西從哪裡來、下一步在哪。
- 常態 idle 動畫每畫面最多一個主要焦點。
- reduced-motion 下移除持續脈動、飛行、震動與大幅位移。

### Density 5

- 首頁低至中密度，一眼看懂核心價值與 CTA。
- 牌桌保持中密度，但只讓「當前目標、家屋、手牌」成為第一層。
- 牌庫、紀錄、秘密目標與完整行動清單放第二層或漸進揭露。
- 每個狀態優先顯示 2–3 個推薦行動，其餘仍可發現。

## 色彩

建議 token：

| 用途 | 色值 | 規則 |
|---|---|---|
| 深森林背景 | #09120F | 主背景 |
| 煙黑背景 | #101311 | 深層、Modal、遮罩 |
| 森林表面 | #17211C | 面板與牌桌表面 |
| 高階表面 | #202A24 | hover／選取前的層次 |
| 骨白文字 | #F1EBDD | 主要文字 |
| 霧灰文字 | #A9B0A8 | 次要文字 |
| 琥珀 | #D89A3D | 唯一主強調色、主要 CTA、關鍵進度 |
| 亮琥珀 | #F0C36B | hover、focus、揭示瞬間 |
| 錯誤 | #C85E52 | 只用於錯誤與危險 |
| 成功 | #6FA77B | 只用於成功狀態 |

規則：

- 琥珀是唯一主強調色，不再讓金、橘、藍、紅同時競爭 CTA。
- 四族既有色只作族群身份條、頭像圈、圖表標記與對局座位辨識。
- 大面積背景不使用高飽和族群色。
- 金框只用於事件揭示、稀有卡檢視、家屋完成與結算等關鍵時刻。

## 字體

- 標題：Noto Serif TC，強調敘事與文化檔案感。
- 介面與內文：Noto Sans TC，強調快速掃讀。
- 數字、行動點與計分可用等寬數字特性，但不另引入未授權字體。
- 標題不全大寫堆疊；英文只作輔助，不凌駕中文。
- 字級至少 16px；重要操作與狀態不依賴 12px 以下文字。

## 版面層級

首頁：

1. 遊戲名稱與一句價值。
2. 可立即理解的玩法證明：卡牌、素材、家屋或 30 秒試玩。
3. 立即試玩 CTA。
4. 族群與文化入口。
5. 商業資訊與版本狀態。

牌桌：

1. 當前回合目標與可用行動點。
2. 中央家屋進度／主要戰場。
3. 玩家手牌與情境推薦。
4. 對手狀態、牌庫與事件。
5. 紀錄、說明與完整行動清單。

## 元件語彙

- Primary button：實心或高對比琥珀，一個區域最多一個。
- Secondary button：煙黑表面加細琥珀邊，不使用持續發光。
- Tertiary action：文字或圖示，不與 Primary 同重量。
- Card：卡面是主角；說明在 hover、focus、tap inspect 或展開層出現。
- Modal：必須有明確標題、目的、主要動作、取消方式與焦點管理。
- Progress：用可理解的分段與數字，不只靠色彩。
- Disabled：降低明度但仍可讀，並提供原因。
- Focus：2px 亮琥珀外框與清楚 offset，不以 hover 代替。

## 動態規格

| 類型 | 建議時間 | 用途 |
|---|---:|---|
| 微互動 | 120–180ms | hover、pressed、focus |
| 元件切換 | 180–280ms | 抽屜、tooltip、選角 |
| 卡牌／素材移動 | 320–600ms | 顯示來源與去向 |
| 場景進場 | 600–900ms | 首頁、事件、結算 |
| 家屋完成 | 800–1400ms | 里程碑演出，一次性 |

限制：

- 動畫不阻止下一個必要操作。
- 不同動畫最多同時兩層。
- 只用 opacity／transform 為主，慎用大面積 blur。
- reduced-motion 以淡入與即時狀態切換替代。

## 文案語氣

- 白話、具體、有行動性。
- 先告訴玩家「現在能做什麼」，再解釋規則。
- 文化內容採尊重、可追溯、避免獵奇的語氣。
- 不使用「神秘部落」「原始」「野性」「異域」等泛化或物化詞。
- 不把所有族群稱為同一個「部落文化」。
- 未確認資料標「待審校」或「待授權」，不要用模糊語氣假裝完成。

## 文化視覺與聲音安全

- 每族建立獨立資料卡、來源、審校者、授權與更新日期。
- 圖紋、服飾、家屋、工藝、祭儀、音樂與傳說不能跨族混用。
- 不自行杜撰族語、拼音或發音；沒有正式資料就留白。
- 不以卡林巴、鼓、笛或自然聲自動等同「原住民／部落感」。
- 現有 battlefield-bg.png 與程序化音色只能視為待審原型，不得直接標記商業定稿。
- 文化審校與權利確認由人類負責；AI 只能整理、標記缺口與產生待審草案。

## 無障礙

- 文字與背景一般至少 WCAG AA 對比。
- 點擊目標至少 44×44 CSS px。
- 所有可點元素可由鍵盤操作，不用 div 假按鈕。
- 圖像有適當 alt；純裝飾圖 alt 留空。
- 不以顏色作唯一狀態訊號。
- Modal 有 focus trap、Escape 規則與關閉後焦點還原。
- 允許瀏覽器縮放，不能設定 maximum-scale=1。

## STEAM 教學任務台

- 視覺定位是遊戲世界中的「任務台」，不是校務系統或表單後台。
- 沿用深森林、煙黑與單一琥珀強調色；學段與主題是控制器，不另開一套彩虹配色。
- 首屏先顯示學段、核心提問、時間與隨機卡牌錨點，再展開 STEAM、流程、評量與來源。
- 證據欄固定區分「看見」「推測」「來源證實」；待審文化項目使用中性警示，不以錯誤紅色製造獵奇感。
- 列印模式改為白底、深色字，隱藏導覽、按鈕與裝飾背景，保留教案 ID、seed、時間軸及來源。

## 事件與骰子動態

- 事件橫幅顯示類別、名稱、說明、牌序與「本輪」時效，避免玩家只看到抽象圖示。
- 互助行動放在可直接看見的群組；競爭與進階行動另列，讓合作不是藏在第二層的附屬選項。
- 骰子動態只表達三件事：出手、空中翻滾、碰撞落定。不得加入與判定無關的持續漂浮或炫光。
- 動畫期間只改 transform 與 opacity；正式骰值只在落定時寫入一次。
- reduced-motion 直接進入結果，不保留無動畫的等待時間。
