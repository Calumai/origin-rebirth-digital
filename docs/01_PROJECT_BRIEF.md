# 01 專案總綱

## 我們要做什麼

把《原地重生・返璞歸真》的現有數位桌遊，改造成具有商業主機遊戲完成度、強互動性與可驗證文化教育深度的網站遊戲。

「像 PS5 大作」指的是完成度、敘事張力、操作回饋、商品可信度與視覺品質，不是複製 PS5 選單或其他遊戲品牌。

## 真正要解決的問題

現況已有完整遊戲循環、四族選角、Bot、連線、交易、猜拳、事件與文化卡，但：

- 首頁像多種遊戲模板與素材的拼接，沒有獨特品牌語言。
- 牌桌資訊同時競爭注意力，玩家知道功能很多，卻不一定知道當下最重要的選擇。
- 互動以按鈕與 Modal 為主，家屋建造與文化卡缺少「我正在操作」的感受。
- 文化內容缺少逐族來源、審校者與授權狀態，商業化風險高。
- 商業網站必要資訊與素材尚未齊全。
- style.css 累積大量覆寫，繼續堆疊會增加回歸風險。

## 受眾

1. 喜歡策略卡牌、桌遊與多人互動的玩家。
2. 想理解臺灣原住民族文化、但沒有基礎的新手。
3. 親子、教師、學校、博物館與文化教育採購者。
4. 評估合作、授權、通路或發行的商業夥伴。
5. 需要用桌機與手機快速試玩的潛在買家。

## 核心價值主張

一句話：

> 蒐集素材、完成工藝、重建家屋；每次策略選擇，都打開一段經審校的文化脈絡。

產品必須同時證明三件事：

- 好玩：玩家能很快理解策略循環與互動張力。
- 有深度：文化卡不只做族別配對，而有來源、說明與延伸閱讀。
- 可商業化：資訊透明、效能穩定、跨裝置可玩、文化權利狀態可追溯。

## 已定設計參數

- Variance 8：高辨識度、非對稱、像遊戲世界中的介面，不做通用模板。
- Motion 7：有電影感與有意義的互動回饋，但不讓動態干擾操作。
- Density 5：中等資訊密度；牌桌保留策略資訊，透過層級與漸進揭露降低壓力。
- 主色系：深森林／煙黑。
- 唯一主強調色：琥珀。
- 四族色：只用於身份、狀態與資料辨識，不搶主 CTA。

## 範圍

本輪改版包含：

- 首頁品牌敘事、玩法證明與開始入口。
- 故事／玩法頁的教育與商業資訊架構。
- 設定頁與連線大廳的操作清晰度。
- 牌桌視覺層級、情境行動、手牌與建屋回饋。
- 結算頁的成就、文化回顧與再玩入口。
- 設計 token、RWD、鍵盤操作、reduced motion。
- 資產效能與商業頁面 metadata。
- 文化內容來源、審校與授權狀態呈現。

## 非目標

- 未經決策不改遊戲規則、計分、卡牌效果、Bot 或連線協定。
- 不在本輪自行新增或翻譯族語。
- 不把未授權素材包裝成商用完成品。
- 不虛構商業數字、獎項、顧問、玩家評價或平台承諾。
- 不把「AAA」理解成堆滿光效、玻璃、金框或高密度 UI。

## 主要產出物

- 可玩的新版網站副本。
- 首頁、故事、設定、大廳、牌桌、結算的桌機與手機版。
- 可重複使用的設計 token 與 UI 狀態規則。
- 文化內容清冊：逐族來源、審校與授權狀態。
- 商業資訊清冊：已確認與待確認欄位。
- 視覺截圖、測試紀錄與獨立驗收報告。
- 可交給 Codex、Claude Code、ChatGPT 或人類接手的工作單。

## 必要資料

人類需提供或確認：

- 正式 Logo、產品副標與品牌署名。
- 支援平台、預計價格、遊戲時間、建議年齡與發行狀態。
- 每族文化資料來源、審校者與授權窗口。
- 圖紋、服飾、音樂、傳說、人物與家屋素材的授權狀態。
- 是否保留或替換現有背景、角色與程序化音樂。
- 商店頁、發行商、隱私與連線服務條款。

## 成功標準

- 新玩家在 30 秒內能說出核心循環：素材 → 選擇 → 家屋。
- 首頁首屏能看出「這是策略遊戲」與「文化內容如何進入玩法」。
- 玩家在牌桌上能立即辨認當前目標、手牌、家屋進度與 2–3 個建議行動。
- 桌機、手機、鍵盤與 reduced-motion 驗收符合 docs/04_ACCEPTANCE_CRITERIA.md。
- 引擎 100 場壓測保持 100/100 完賽。
- 所有對外文化項目都有逐族來源、審校與授權狀態；沒有 AI 杜撰族語。
- 未確認的商業資訊明確標示待決，不被寫成事實。

## 主要風險

- 文化挪用或把不同族群混成單一「部落風」。
- 舊 CSS 覆寫造成 RWD 與互動回歸。
- 大型背景與低解析卡面影響效能及商品質感。
- PeerJS CDN／broker／TURN 造成連線不穩。
- 動態過多影響可讀性、暈動敏感與低階裝置。
- UI 重構意外改到遊戲規則。

## 2026-07-17 功能擴充

依使用者試玩回饋，本輪已由單純 UI 改版擴充為「回合互動＋STEAM 教學」版本：

- 公共事件由 6 張擴為 14 張，增加天候、材料試驗、交流市集、互助工班與共學情境。
- 新增「分享素材」與「共學交流」兩種正向玩家互動，並以最高 5 分的互助分鼓勵合作，不改變家屋數優先的勝負主軸。
- 擲骰改為出手、翻滾、落定三階段，並防止快速連點造成重複正式判定。
- 新增 STEAM 教學任務台，可依國小 1–2、3–4、5–6、國中、高中五個程度，隨機產生五類氣候與建築模型教案。
- 教案只把現有卡牌當作觀察物；任何真實族群建築敘述仍需可追溯來源與文化顧問審校。

### 擴充後成功標準

- 一局內不只出現競爭行動，玩家也能看見並完成至少兩種互惠選擇。
- 14 張事件均有可理解的當輪效果，且自動化測試可覆蓋新增規則。
- 五學段 × 五主題全部可生成，活動時間總和精確等於學段時長。
- 同一 seed 與選項可重現同一份教案，便於教師備課、分享與驗收。
- 教案清楚區分遊戲卡面、學生假設、官方資料與待文化審校內容。
